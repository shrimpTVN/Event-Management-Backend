🔑 Google OAuth – Lấy ID Token

Trang test để lấy Google ID Token đúng với client_id của bạn, dùng thử API /api/auth/google

1

Đăng nhập bằng Google

2

ID Token ✓ Đã lấy được

Chưa có – hãy đăng nhập Google ở bước 1.
3

Test API trực tiếp hoặc dùng Postman

Hoặc copy token và dán vào Postman: POST http://localhost:8080/api/auth/google

Body → raw → JSON: 
{
  "idToken": "<paste token vào đây>"
}
